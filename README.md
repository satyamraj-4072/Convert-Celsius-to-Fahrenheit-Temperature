# Celsius to Fahrenheit Converter in C

A simple C program that converts a temperature from Celsius to Fahrenheit using the standard conversion formula. This project is ideal for beginners learning C programming, arithmetic operations, variables, and formatted output.

---

## 🚀 Features

- Convert temperature from Celsius to Fahrenheit
- Simple and beginner-friendly implementation
- Demonstrates arithmetic calculations in C
- Easy to understand and modify

---

## 🛠️ Technologies Used

- C Programming Language
- GCC Compiler (or any standard C compiler)

---

```
Celsius-to-Fahrenheit-Converter/
│── main.c

```

## ▶️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/celsius-to-fahrenheit-converter.git
```

### Navigate to the Project Directory

```bash
cd celsius-to-fahrenheit-converter
```

### Compile the Program

```bash
gcc main.c -o converter
```

### Run the Program

```bash
./converter
```

## 📖 Formula Used

```
Fahrenheit = (Celsius × 9 / 5) + 32
```
